# 💻 Código-Fonte (`src/`)

## 📌 Introdução

A pasta `src/` (*source*) é o núcleo funcional do **Sistema de Login**. É aqui que reside todo o código-fonte em Java responsável por implementar as regras de negócio, controle de acesso, autenticação e gerenciamento de usuários.

Este código foi estruturado aplicando os princípios fundamentais da **Programação Orientada a Objetos (POO)** — como **Encapsulamento**, **Herança**, **Polimorfismo** e **Abstração** —, além de seguir padrões de arquitetura (como MVC e DAO) para manter o código limpo, modular, testável e de fácil manutenção.

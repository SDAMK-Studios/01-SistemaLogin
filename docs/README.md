# 📑 Documentação Técnica e Visual (`docs/`)

## 📌 Introdução

A pasta `docs/` é o repositório central de toda a **documentação arquitetural, técnica e de interface (UI/UX)** do módulo de **Sistema de Login**. 

No desenvolvimento de software orientado a objetos, a documentação visual e conceitual desempenha um papel crucial para garantir o alinhamento da equipe, facilitar a manutenção contínua e demonstrar a correta aplicação dos conceitos de modelagem (como UML e design de experiência do usuário). Este diretório reúne desde as primeiras ideias estruturais até os diagramas formais e apresentações do projeto.

---

## 📁 Estrutura de Diretórios

```text
docs/
│
├── README.md                 # Documentação do diretório docs/

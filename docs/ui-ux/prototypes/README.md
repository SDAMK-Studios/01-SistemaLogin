# 🖱️ Protótipos Interativos (`prototypes/`)


## 📌 Introdução

A pasta `prototypes/` reúne os protótipos e modelos de fluxo utilizados para representar a navegação, as transições e a experiência de interação entre as telas do **Sistema de Login** e do seu ecossistema.

A prototipagem é uma etapa fundamental do design de interface (UI/UX), pois permite simular os comportamentos planejados da aplicação — como validações de credenciais, navegação entre menus e fluxos de erro —, garantindo que a arquitetura do sistema esteja alinhada antes e durante o desenvolvimento do código em Java.

---

## 🔄 Fluxo de Navegação e Interação

Esta pasta registra os protótipos utilizados para representar a navegação e a interação entre as telas da aplicação.

### 🔑 Fluxo Inicial

* **Login Válido:**
  * Tela de Login → Validação → Tela de Seleção

* **Login Inválido:**
  * Tela de Login → Mensagem de erro → Tela de Login

---

### 📇 Agenda de Contatos

* **Acesso:**
  * Tela de Seleção → Agenda de Contatos

---

### 🎮 PokeIf

* **Acesso:**
  * Tela de Seleção → PokeIf

---

### ⬅️ Voltar

* **Retorno:**
  * Tela de Seleção → Tela de Login

---

## 📌 Observações

Os protótipos representam o comportamento planejado para a aplicação e poderão ser refinados durante o desenvolvimento.

# ✏️ Wireframes e Esboços Iniciais (`wireframes/`)

## 📌 Introdução

A pasta `wireframes/` reúne os esboços estruturais e rabiscoframes (*sketches*) de baixa fidelidade do **Sistema de Login** e das telas do ecossistema da aplicação.

O desenvolvimento de wireframes é a primeira etapa do processo de design de interface (UI/UX). Eles servem para estruturar a disposição dos elementos visuais, planejar o fluxo de navegação entre as telas e validar os requisitos do sistema de forma rápida e conceitual, antes de avançar para a criação de mockups digitais e implementação do código em Java.

# 📂 Suporte e Materiais Complementares (`support/`)

## 📌 Introdução

A pasta `support/` reúne todos os materiais auxiliares, documentações complementares, mídias de demonstração e referências técnicas utilizadas no desenvolvimento do módulo de **Sistema de Login**. 

O objetivo desta estrutura é centralizar recursos que facilitem a compreensão do projeto por parte dos avaliadores, novos desenvolvedores e usuários da aplicação, garantindo uma documentação rica e completa.

---

## 📁 Estrutura de Diretórios

```text
support/
│
├── README.md         # Documentação da pasta de suporte
├── documents/        # Documentos de apoio, requisitos e especificações
├── videos/           # Vídeos de demonstração, testes e apresentações
├── tutorials/        # Guias passo a passo para configuração e execução
└── references/       # Referências bibliográficas, artigos e links úteis
